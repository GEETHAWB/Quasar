# Quasar
Quasar is a ray-traced rendering engine built with modern Vulkan and bleeding edge C++ in attempt for me to get better with this damn language 

## Building
The project is built with CMake however I've created a Makefile with specific commands to make compilation and running easier. 
Common commands include: "run", "clean", "configure", and "build".
This project also primarily uses the Ninja build system due to its incredible build speeds.

## AI
AI has been used for research but the code and logic was handcrafted by me

## Libraries
This project (unlike previous attempts) will actually use libraries to make the Vulkan loading and allocation processes easier.
